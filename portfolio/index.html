실행형 데이터 분석가

I'm LEE Ji-Eun
I'm a

데이터가 진짜 가치를 발휘하는 순간은,

분석 결과가 실제 비즈니스에 적용되어

눈에 보이는 변화를 만들어낼 때라고 믿습니다.


저는 전략을 세우고, 데이터를 설계하며,

분석, 모델링을 통해 실행 가능한 방향을 제시해 온 실행형 데이터 분석가입니다.

CRM, 유통, 물류, 서비스 등 다양한 도메인을 넘나들며 문제를 정의하고,

직접 데이터를 다루며 전략 수립부터 실행과 성과 검증까지 전 과정을 수행하고 있습니다.


저는 서비스 기획, 데이터 분석, 시스템 개발 등 새로운 영역의 배움과 실행을 수용하며,

사람과 데이터를 잇는 역할의 폭을 계속 넓혀가고 있습니다.

My Strength

1. 탄탄한 문제 이해력

사용자 행동과 서비스 흐름을 먼저 살펴보고,

어떤 문제를 풀어야하는지 구체적으로 정의함


분석이 곧바로 전략과 실행으로

이어질 수 있도록 탄탄하게 준비

2. 자나깨나 해석오류 조심

좋은 분석은 깨끗한 데이터에서 시작되기에,

수집 설계부터 데이터를 꼼꼼히 점검하고,


분석 전에 "이 데이터로 말해도 되는지"를

먼저 확인하는 데 시간을 아끼지 않음

3. 헛질과 그래프를 조심해

멋있어 보이는 그래프보다,

지금 의사결정에 꼭 필요한 질문이 먼저.


목적과 가설을 미리 정의하고,

"그래서 어떤 결정을 도울 수 있는지" 제시


4. 오류도, 통찰도 결국 사람

잘못 설계된 데이터와 애매한 지표는

사람의 행동을 오해하게 만드는 가장 큰 장벽.


현장과 대화하며 지표를 다시 정의하고,

데이터 뒤에 있는 사람과 상황을 함께 분석함

5. 결과는 쉽게, 명확하게

어려운 분석 모델이라도

결과는 누구나 이해할 수 있어야 함


복잡한 수식 대신 핵심 지표 1~2개로,

"무엇을 줄이고, 무엇을 늘리지" 한눈에 보이도록

6. 시작과 끝은 Log부터

"무엇을 남기고, 어떻게 쓸 것인가"로 출발

유관부서와 함께 분석 로그를 설계하고,


전략과 성과를 끝까지 추적하는

전략형 데이터 분석가를 지향
